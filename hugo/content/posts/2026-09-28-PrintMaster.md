---
title: Rebuilding an old Atari ST Software - PrintMaster
date: 2026-09-28
---

PrintMaster is an old program that was published in 1985 on the Atari ST.
This software allowed you to create stationneries, banners and greeting cards
from a large selection of fonts and icons.

At home, we used and abused this software to print random greeting cards with
our noisy printer, and it was fun. It was one of the many pirated disks we had
at that time (certainly something for another post one day).

The other day, I threw the disk image at my agent and together, we disassembled
all the code and rebuilt a web-based version of the greeting card editor. It's
now working as a self-hosted HTML app that you can use for your great pleasure.

Find it here on [Github](https://octplane.github.io/printmaster-web/card.html).
